# 小红书 Build in Public 发布计划

> 对应赛道 07（小红书 · Build in Public）。核心玩法：**把从 0 到 1 的过程公开地晒出来**，让社区参与。
> 奖项：一等 15000 / 二等 9000 / 三等 3000 / **社区人气奖 3000（纯看小红书笔记数据 + 内容质量）**。

## 赛道硬要求（核对官方）
相信社区链接人与人的能力，相信 在Builder的手中，AI 将赋能每一个普通人。

参赛要求
1）项目需为 AdventureX 期间开发，具备可现场演示的原型。
2）Build in Public（公开构建）—— 本赛道核心玩法。 
不只交付成品，更把从 0 到 1 的过程"晒出来"： · 在小红书持续发布构建记录（笔记/视频）——立项初衷、踩过的坑、改过的方向、深夜的灵感、第一条用户反馈 · 让社区参与进来——真诚分享，主动回应评论与建议，在被看见的过程中收获伙伴、灵感与共创 · 我们相信：公开地做，比默默地做走得更远；一个好项目，值得被一群人接住
3）落地小红书的潜力——能在小红书生态被使用/传播/商业化（内容/社区/直播/开店/广告/商单）
4）软硬件不限

## 3 天内容日程（建议）

| 时间 | 发什么 | 对应赛道要求 |
|---|---|---|
| Day 0 | **立项笔记**："我们想让'不敢开口'的人也能从容说话" —— 讲初衷 + Even 眼镜/戒指开箱 | 立项初衷 |
| Day 1 | **踩坑/深夜灵感**：比如"戒指 tap/swipe 老误触，我们怎么解决的"、"防回声死循环的坑" | 踩过的坑 |
| Day 2 | **第一条用户反馈**（最强素材）：真实用户/评委试用的短视频（⚠️ 匿名 + 已获同意） | 第一条用户反馈 |
| Day 2 | **主动提问贴**：评论区问"你身边有'能听能想却开不了口'的人吗？" 收集共鸣并回应 | 让社区参与 |
| Day 3 | **Demo 成片** + 收尾故事："让表达，对每个人都再容易一点" | 落地传播 |

> 节奏原则：Build in Public 要"真诚"，不求精致——手机随手拍开发花絮即可。每天至少 1 篇，评论务必回。

## 赛道提交问答（草稿，最后统一定稿）

1. **你的项目是什么？解决了谁的什么问题？**
   > 面向"能听、能想、却卡在'说出口'这一步"的人（社恐、发音不标准、思维节奏不同）的社交表达搭子：眼镜听懂对方的话，AI 生成候选回复显示在眼前，戒指一选，手机代你说出口。
2. **你希望在小红书用什么方式让它被更多人看见？**
   > 用真实的 Build in Public 过程 + 无障碍/神经多样性议题的共鸣，带动同类人群与家属的讨论与转发。
3. **开发过程中吸收了哪些小红书用户/作者的建议或启发？**
   > （运营中真实填写：把评论区收到的建议、被启发的调整记录下来。）
4. **你想在小红书对接哪些资源、产品或伙伴？**
   > 无障碍公益组织、听障/神经多样性社群作者、康复/特教领域从业者。
