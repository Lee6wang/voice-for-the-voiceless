## 通用提醒

### 每篇必做
- [ ] 检查话题标签（至少带 `#AdventureX` `#BuildInPublic`）
- [ ] @ 小红书官方账号（按赛道要求确认具体账号名）
- [ ] 配图/视频已确认无隐私问题
- [ ] 发布后 **30 分钟内** 回复前 3 条评论（提升算法推荐）

### 绝对红线
- ❌ 不说"治疗/治愈失语症"，不宣称医疗功效
- ❌ 不承诺未经验证的性能（"100% 识别""零延迟"）
- ❌ 真实用户故事**必须匿名 + 本人同意**
- ❌ 不消费用户困境、不卖惨博流量
- ❌ 不暴露 API Key / 后端地址等敏感信息

### 语气指南
- 真诚 > 精致，随手拍 > 精修图
- 平视用户，不同情不猎奇
- 讲"让表达对每个人都再容易一点"
- 可以适当自嘲踩坑，但不要抱怨

### 赛道提交问答（赛后统一填写）
1. **你的项目是什么？** → 见 [项目速览](../项目速览-对外文案素材.md)
2. **你希望怎么让它被更多人看见？** → 用真实的 Build in Public + 无障碍议题共鸣
3. **吸收了哪些社区建议？** → 🔲 **运营期间记录评论区有价值的反馈**（见 [05-提问互动](05-提问互动.md) 社区建议记录表）
4. **想对接哪些资源？** → 无障碍公益组织、听障/神经多样性社群、康复/特教从业者
