## 工作顺序

1. 逐项完成 `copy/project-copy.md`；
2. 文案定稿后确定视觉主标题和关键信息；
3. 按 `assets/README.md` 的规格制作并导出图片；
4. 在 Gallery 创建项目并预览；
5. 最后提交前复核本页清单。
