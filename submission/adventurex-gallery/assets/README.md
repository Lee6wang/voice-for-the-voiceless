# Gallery 视觉素材

本目录保存用于 AdventureX Gallery 的最终视觉素材。源文件与导出文件应使用
清晰、稳定的英文文件名。

## 导出清单

| 建议文件名 | 尺寸 | 用途 |
|---|---:|---|
| `cover-16x9.png` | 推荐 `1920 × 1080 px` | 项目封面、第一张媒体图片 |
| `banner-card-440x140.png` | `440 × 140 px` | 首页项目卡片 |
| `banner-detail-1920x320.png` | 至少 `1920 × 320 px` | 项目详情页顶部 Banner |
| `gallery-01-product.png` | 建议 `16:9` | 眼镜、戒指与手机整体产品图 |
| `gallery-02-hud.png` | 建议 `16:9` | HUD 转写与 4 条候选 |
| `gallery-03-flow.png` | 建议 `16:9` | 听见、选择、发声的完整流程 |
| `gallery-04-settings.png` | 建议 `16:9` | 手机配置与可控学习 |

当前定稿封面：`cover-16x9.png`（艺术字版 v5，`1920 × 1080 px`）。

当前 Gallery 相册定稿共 4 张，均为 `1920 × 1080 px`：

- `gallery-01-product.png`：Even G2、R1、手机与 Candidate Agent 的产品整体；
- `gallery-02-hud.png`：基于真实浏览器预览采集的 G2 HUD 与四条候选；
- `gallery-03-flow.png`：听见现实、获得可能、亲自选择、回到对话；
- `gallery-04-settings.png`：基于真实设置页采集的表达偏好、隐私与可控学习。

## 构图规则

- Logo、项目名和关键人物放在画面中央；
- 卡片 Banner 需要兼容 `360–440 px` 的动态宽度，避免把重要内容放在两侧；
- 详情 Banner 的关键内容放在中央约 70% 区域；
- 详情内容会向上覆盖 Banner 底部约 `80 px`，底部不要放标题或关键操作；
- 所有文字在缩小到卡片尺寸后仍需清晰可读；
- 不使用未经授权的人物、品牌素材或用户隐私信息。

## 文件管理

- 最终上传文件直接放在本目录；
- 可编辑源文件放入后续建立的 `source/` 子目录；
- 同一素材的修订版使用版本号，例如 `banner-card-440x140-v2.png`；
- 定稿后删除文件名中的版本号，仅保留本页约定的标准名称。
